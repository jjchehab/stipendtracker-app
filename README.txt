StipendTracker (web version) - preview
======================================

To try it: double-click index.html (best in Google Chrome).

Your data is saved inside the browser on this computer. Use Settings > "Save backup file"
now and then. The backup file has the same format as the Mac app's data file.

Import: on Home, press "Import PDF" and choose the movements PDF from the Santander app.

Folders:
  index.html        the page you open
  css/              the look
  js/store.js       the budget rules (a port of the Mac app's BudgetStore)
  js/bankimport.js  reads the Santander PDF and finds the purchases
  js/app.js         the screens
  js/vendor/        pdf.js 3.11.174 (Apache 2.0, Mozilla), used to read PDFs
  fonts/            Montserrat (free, SIL Open Font License)
